# 개인 채용 보드

- `/`: 기존 공개 이력서
- `/jobs`: 로그인 전용 공고 수집·등록·필터·경험 비교·지원 상태 관리
- `/jobs/profile`: PDF/DOCX/TXT 텍스트 추출과 프로필·출퇴근 기준 위치 저장

개인 데이터는 이제 브라우저 localStorage가 아닌 별도 백엔드의 SQLite/PVC에 저장합니다. 기존 브라우저 자료는 삭제하거나 자동 전송하지 않습니다.

서버 비밀번호 설정과 Argo CD PVC 허용이 필요합니다. 구현 범위·미지원 기능·배포 순서·검증 방법은 [백엔드 배포 안내](jobs-backend.md)를 참고하세요.
