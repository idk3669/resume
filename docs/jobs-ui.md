# 개인 채용 보드 화면

## 경로

- `/` 기존 공개 이력서
- `/jobs` 공고 목록, 필터, 경험 키워드 비교, 관심/지원 완료/제외 상태
- `/jobs/profile` 추천 프로필 편집, 희망 직무, 출퇴근 기준 위치

## 현재 동작

외부 채용 데이터 없이 실행할 수 있는 화면 구현 단계다. 최초에는 빈 목록이며 사용자가 공고 본문을 직접 등록할 수 있다. 별도로 선택한 미리보기에는 가상 회사 4곳만 표시된다. 실제 공고와 예시는 목록을 섞지 않는다.

직무, 지역, 직원 수, 근무방식, 검색어 필터가 동작한다. 거리 데이터가 없는 공고는 거리 제한에서 제외되며, 지도 API는 아직 연결되지 않았다. 경험 연결순은 명시된 기술 키워드 비교이며 LLM의 추천이나 합격 예측이 아니다. 회사 실무, 개인 프로젝트, 테스트 경험을 별도로 비교한다.

개인 설정과 직접 등록 공고는 `career-v1-*` 키로 브라우저 localStorage에 저장한다. 서버로 전송하지 않는다. 브라우저 데이터 삭제 시 사라지며 다른 기기와 동기화되지 않는다. 예시 공고의 상태와 실제 공고의 ID는 구분된다.

TXT 파일은 로컬에서 읽어 확인 후 선택한 경력 영역에 반영할 수 있다. PDF/DOCX 선택 시 파일명을 알리고 자동 분석 미연결 상태를 표시한다. 이들 파일은 저장·전송·분석되지 않는다. 본문 붙여넣기를 대안으로 제공한다.

## 후속 연동

본인 인증은 미구현이다. 개인용 서버 데이터 API를 추가할 때 인증과 소유자 확인을 먼저 적용해야 한다. 브라우저 저장은 인증 수단이 아니다.

공고 수집, PDF/DOCX 파싱, LLM 분석, 지도/거리 계산, DB/파일 저장소는 별도 서버 연동 작업이다. 현재 버전은 이러한 기능이 완료됐다고 표시하지 않는다. 기존 Nginx SPA fallback이 `/jobs`와 `/jobs/profile` 새로고침에 사용된다.
